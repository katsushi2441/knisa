# Kurage NISA 枠計算・試算（knisa）

新しいNISAの枠があといくら使えるか、売った分が翌年いくら復活するかを、取引を入れて計算します。
積み立ての試算は「配当＋企業の利益の伸び−信託報酬」から、良かった場合・悪かった場合の幅で出します。

デモ: https://proto.exbridge.jp/knisa.php

## 答えること・答えないこと

- 答える: 年間投資枠（つみたて120万円・成長240万円）の残り、非課税保有限度額（簿価で1,800万円、うち成長1,200万円）の残り、売却した簿価が翌年に復活する額、積立の幅
- 答えない: どの商品を買うべきか（特定の金融商品は勧めない）

## 枠のルール（金融庁「NISAを知る」「よくある質問」2026-09-27 確認）

| ルール | 実装 |
|---|---|
| 年間投資枠は簿価で、売っても戻らない | 買った額だけで年間の上限を見る |
| 非課税保有限度額は簿価で管理 | 年初の簿価＋その年の購入で上限を見る |
| 売った分は翌年以降に復活 | その年の売却で空いた分は、翌年の枠にだけ効かせる |
| 2023年までのNISAは外枠 | 計算に入れない |

売却は「売った商品の簿価（買ったときの金額）」で入れます。売却代金ではありません。

## 構成

- `knisa.php` … 画面（PHP 1枚。heteml などの共有サーバーにそのまま置ける）
- `knisa-core.js` … 計算（画面とテストで同じものを使う）。入力はブラウザの外に出さない
- `tests/core.test.js` … 制度のルールを手で計算した答えと突き合わせる（`node tests/core.test.js`）
- `make_ogp.py` … OGP画像（1200×630）

## 試算について

予想ではなく、置いた仮定から出る幅です。年率（中央）＝配当利回り＋利益の伸び−信託報酬とし、
株価の割高・割安の変化は長い目で見て平均0と置いています。値動きの大きさ（年率の標準偏差）から
種つき乱数で1,500通り試し、下位10%・中央・上位10%を出します。同じ入力なら同じ結果になります。
