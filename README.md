# Kurage NISA 枠計算・試算（knisa）

新しいNISAの枠があといくら使えるか、売った分が翌年いくら復活するかを、取引を入れて計算します。
積み立ての試算は「配当＋企業の利益の伸び−信託報酬」から、良かった場合・悪かった場合の幅で出します。

デモ: https://proto.exbridge.jp/knisa.php

## 答えること・答えないこと

- 答える: 年間投資枠（つみたて120万円・成長240万円）の残り、非課税保有限度額（簿価で1,800万円、うち成長1,200万円）の残り、売却した簿価が翌年に復活する額、積立の幅
- 答える: つみたて投資枠の対象商品（金融庁の一覧）が、どの指数に連動し、どの地域の株を持つか。持っている指数どうしの重なり
- 答えない: どの商品を買うべきか（特定の金融商品は勧めない。一覧は名前順で、成績や人気では並べない）

## 枠のルール（金融庁「NISAを知る」「よくある質問」2026-09-27 確認）

| ルール | 実装 |
|---|---|
| 年間投資枠は簿価で、売っても戻らない | 買った額だけで年間の上限を見る |
| 非課税保有限度額は簿価で管理 | 年初の簿価＋その年の購入で上限を見る |
| 売った分は翌年以降に復活 | その年の売却で空いた分は、翌年の枠にだけ効かせる |
| 2023年までのNISAは外枠 | 計算に入れない |

売却は「売った商品の簿価（買ったときの金額）」で入れます。売却代金ではありません。

## 対象商品の一覧を更新する

金融庁「つみたて投資枠対象商品届出一覧（対象資産別）」の Excel を取ってきて、次を実行します。

```bash
python3 scripts/build_funds.py data/<落とした一覧>.xlsx <一覧の日付 例: 2026-09-18>
```

`knisa-funds.json` が作り直されます。見出しに書かれた本数と読み取った行数が合わないとき、
地域の分類が無い指数が出てきたときは、止まって知らせます（表の形が変わったか、新しい指数が増えたとき）。
画面には「金融庁の一覧を加工して作成」と出典を表示します（公共データ利用規約 第1.0版）。
手数料（信託報酬）はこの一覧に無いので載せていません。

## 置き方（自社・事務所のサイトに）

1. `knisa.php` と `knisa-core.js`（と `knisa-funds.json`）を同じ場所に置く（PHP 8 が動く共有サーバーでよい。DBは使わない）
2. `knisa-config.sample.php` を `knisa-config.php` に写して、社名・ロゴ・色・相談先を書き換える
3. 設定が無いと、社名もロゴも出さず、アクセス計測もしない素の画面になる

入力された取引はブラウザの中だけで計算し、サーバーへは送りません。

URL で最初の状態を選べます（説明会で「この例」を開くとき、紹介動画を撮るときに使う）。

- `?ex=full` … 5年で枠を埋めて6年目に売る例／`?ex=same` … 売った年に買い直す例（上限超過になる）
- `?fq=全世界` … 対象商品を名前で検索した状態
- `?ovl=S%26P500|MSCI%20ACWI%20Index` … 指数の重なりを選んだ状態

## AIアシスタントから使う（MCP）

`knisa_mcp.php` は、AIアシスタントが NISA の枠の質問に、記憶ではなく制度どおりの計算で答えるための
MCP サーバーです（stdio・PHP 1枚・書き込みと外部通信なし）。

```bash
claude mcp add knisa -- php /path/to/knisa_mcp.php
```

| ツール | 答えること |
|---|---|
| `nisa_rules` | 枠のルール（出典つき） |
| `nisa_check_waku` | 取引履歴から、年ごとの残り・翌年に使える生涯の枠・復活額・上限超過 |
| `nisa_frame_fill` | 毎月の積立額が年間枠のどこに入るか、生涯の枠が何年で埋まるか |
| `nisa_fee_gap` | 信託報酬の違いで将来いくら差が出るか（商品の推奨はしない） |

「売ったらその年の枠も戻る」「売った年のうちに生涯枠を使える」といった、よくある間違いを計算で正せます。

## 構成

- `knisa.php` … 画面（PHP 1枚。heteml などの共有サーバーにそのまま置ける）
- `knisa-core.js` … 画面の計算。`knisa-core.php` … 同じ計算の PHP 版（MCP が使う）
- `knisa_mcp.php` … MCP サーバー
- `knisa-config.sample.php` … 設定の見本
- `knisa-funds.json` … 対象商品の一覧（`scripts/build_funds.py` で金融庁の Excel から作る）
- `tests/core.test.js` … 制度のルールを手で計算した答えと突き合わせる（`node tests/core.test.js`）
- `tests/parity.test.php` … PHP 版と JS 版の答えが一致するか（`php tests/parity.test.php`）
- `tests/mcp.test.py` … MCP を stdio で叩く（`python3 tests/mcp.test.py`）
- `make_ogp.py` … OGP画像（1200×630）

## 試算について

予想ではなく、置いた仮定から出る幅です。年率（中央）＝配当利回り＋利益の伸び−信託報酬とし、
株価の割高・割安の変化は長い目で見て平均0と置いています。値動きの大きさ（年率の標準偏差）から
種つき乱数で1,500通り試し、下位10%・中央・上位10%を出します。同じ入力なら同じ結果になります。
